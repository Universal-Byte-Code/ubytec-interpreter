# Native Ubytec temporal runtime (bootstrap)
 
The implementation language of the runtime is Ubytec. The existing C# temporal reference is retained as an executable oracle, not a dependency of the native scheduler. Compile `temporal.ubc` via the normal source -> indexed UBCM -> x64 pipeline. No Python, additional opcode encoding, or C# turn callback is involved in native execution.

## Admission and ABI (internal, not frozen)
 
This slice consumes the exact Code bytes of one externally admitted, zero-argument/local Int64 function. The supported wire forms are TRAP, NOP, CLEAR, NULL, PUSH (1–8 byte little-endian immediate), all core stack operations 0x12–0x1E, arithmetic 0x20–0x2A, bitwise 0x30–0x36, comparisons 0x40–0x49, inferred RETURN (09 00), and the four extended-stack forms (FF 10 op u16). No new wire opcode is allocated. The public module entry now performs bounded admission of complete PMF bytes for this restricted executable projection; it is not a general PMF verifier. The caller must supply valid, non-overlapping native buffers with the documented extents and an immutable code slice; the runtime itself uses UnsafeCells because it operates on these trusted host buffers. Guest stack cells are not host pointers. Unknown/truncated instructions, resource exhaustion and invalid stack depths produce infrastructure failure, not a successful guest event.
 
- `TemporalTurn(code, length, state, cells, capacity, quantum)` executes one primary boundary. State has six u64 cells (PC, depth, cumulative fuel, phase, last instruction byte offset, result). The caller supplies zero initial state and a capacity-sized u64 evaluation stack. Phase zero denotes pending entry; phase five denotes terminated; phase six denotes failed. Boundary results are 0 Enter, 1 Budget, 2 Return, 3 Trap, 4 Abort, 5 Terminate, 6 Failure. Terminal lifecycle transitions charge no guest fuel.
- `TemporalRun(code, length, states, stacks, contexts, capacity, quantum, ledger, limit)` owns the entire serial scheduling loop. States require contexts * 64 bytes (six state cells, local sequence and logical clock); stacks require contexts * capacity * 8 bytes; ledger requires limit * 72 bytes. Contexts are 1..128; capacity 1..4096; limit at most 1,000,000; positive quantum. Context creation is emitted in round zero. Each round visits nonterminated contexts in ascending order. Return value is committed row count, or zero on failure (discard the partial ledger). No host scheduling callback.
- A row is nine little-endian u64 cells: round, context ordinal, local event sequence, Lamport time, commit ordinal, boundary kind, cumulative guest fuel, Code offset (0xffffffff for synthetic transitions), result. Kind 7 is creation (coordinator ordinal zero; result is created ordinal). Other result fields are zero unless Return. Context/instance/activation GUID/digest are not serialized in this projection; loaded instance and single activation are implicit in this restricted bootstrap. This projection is not the complete temporal event schema.

## Scalar execution

`TemporalPrivateDepth` validates required stack depth and resulting capacity for both admission and execution. `TemporalPrivateApply` implements private cell operations in Ubytec; execution charges one guest instruction regardless of helper instruction count. Integer arithmetic wraps modulo 2^64 except DIV/MOD/UDIV/UMOD, which trap on zero, and signed DIV/MOD also trap on min-int / -1 before native division. ABS of min-int preserves its bit pattern. Shift counts use the low six bits; signed and unsigned comparisons yield canonical 0/1. PUSH16 is a zero-extended two-byte read in the native top-first stack byte layout (including cross-cell words); the other extended forms index cells, not bytes. Internal dispatch value 273 distinguishes PUSH16 from core PUSH; it is not a new guest opcode.

## Complete module admission

- `TemporalAdmit(image, length, capacity, view)` reads the actual PMF header and section headers in Ubytec, enforces version 0.0, 12-byte framing, ordered unique section kinds, bounded payload lengths, required section set, critical flags and context wire version 3 / DirectOnly. It admits exactly one top-level zero-argument/local Int64 function, empty string/import/export/constant tables, no contract/capability manifests or callable slots, and optional entrypoint 0 or NoIndex. Unknown noncritical extensions are skipped. The AST payload is opaque and nonempty; canonical JSON and unused type entries are not validated. The executable type used by the function is checked, including modifiers, array extent, name and reserved fields.
- It independently scans the entire supported straight-line Code stream, checks immediate framing and stack depth/capacity, and requires a final RETURN or TRAP. Unsupported or malformed instructions fail before any scheduler event is published. Code tails after a terminal instruction are rejected in this bootstrap.
- `TemporalRunModule(image, length, states, stacks, contexts, capacity, quantum, ledger, limit, view)` calls admission then runs the scheduler. The host supplies a separate 16-byte scratch view; admission writes the pointer/length only on success. Immutable disjoint buffer preconditions still apply. This is executable-projection admission, not authentication or a sandbox for arbitrary native callers.

## Validation
 
`PortableSelfHostedTemporalTests` compiles the Ubytec runtime, assembles and runs its native scheduler, and compares its projected rows against the C# oracle on actual verified UBCM code, including exact-quantum return, multi-context order, signed/unsigned arithmetic, shifts, comparisons, stack permutations and cross-cell PUSH16, and trap/abort. Explicit stack vectors compare results against direct native lowering as a third reference. It tests malformed/unsupported code and resource limits separately. The C# test harness supplies host buffers and bytes; it does not select turns, evaluate guest opcodes or assign event order for the native run.

The bootstrap uses a single code stream shared by all initial contexts; it does not yet support arbitrary modules, parallel workers, protected process isolation or full temporal-v0 conformance. Retain the managed oracle until differential coverage is established.
